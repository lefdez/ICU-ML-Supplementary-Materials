# Contributing Guidelines

Thank you for your interest in our research repository.

## Academic Artifact & Peer-Review Status
This repository contains source code and data supporting a doctoral dissertation and associated manuscript submitted for peer review. 

* **Pull Requests:** To ensure reproducibility and preserve the exact state of the published methodology, **we are not accepting code contributions, enhancements, or pull requests**.
* **Reusing the Project:** You are welcome to fork, modify, or use the code (under the **MIT License**) and the datasets (under **CC BY 4.0**) in your own projects, provided proper attribution is given.

## Feedback & Questions
If you are a reviewer, researcher, or reader with questions, bug reports, or feedback regarding the paper, please open a GitHub Issue or contact the authors directly using the contact information provided in the `README.md`.
