# Security & Vulnerability Policy

## Reporting Issues

If you discover a security vulnerability, data issue, or critical implementation flaw in this repository, please avoid opening a public issue. 

Instead, please contact the lead authors directly:
* **Luis E. Fernandez-Curbelo**, Tania Rivero-Blanco, Carlos Cruz Corona, Igor Zwir

Refer to the contact details provided in the main `README.md` file. We will review and respond to private reports as soon as possible.
